# Customer guide

Open the application and choose Customer. Use the language dropdown for English, Hindi, or Marathi and the sun/moon control for Light or Dark mode. Open Scanner, choose a sample product from the library, wait for the simulated analysis, review the result and bounding boxes, then download the summary PDF.

Use the dashboard action or the header profile button to view the six teammates. The current prototype does not perform live camera/OCR analysis; it demonstrates the flow with prepared sample datasets.
