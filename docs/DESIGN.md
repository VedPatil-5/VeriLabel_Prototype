# Design system

The existing light design is the baseline: white/lilac surfaces, VeriLabel blue, navy headings, rounded cards, Inter body text, Plus Jakarta Sans display text, compact mobile navigation, and restrained motion.

The application now adds semantic surface/border/text variables for dark mode without replacing the light identity. Language and theme controls are shared and keyboard accessible. The Officer Assistant is a bottom-right circular FAB with safe-area spacing. Dashboard cards collapse to readable mobile sections; tables use horizontal scrolling where necessary.
