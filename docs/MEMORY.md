# Project memory

VeriLabel is a frontend-only prototype. Customer scanning is sample-library based and simulated. Officer authentication is intentionally dummy client-side authentication. Officer records and Mumbai analytics are prototype sample data, not government statistics.

Language preference uses `verilabel:language`; theme preference uses `verilabel:theme`; the demo officer session uses `verilabel:officer`. Keep these independent. Preserve the current customer design and reuse the scanner/team components.
