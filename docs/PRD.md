# VeriLabel PRD

VeriLabel is a prototype for packaged-label verification: “Every Label, Verified.” It serves customers and prototype Legal Metrology officers. Customer scanning currently uses six static sample datasets and a simulated OCR/rule pipeline. Officer workflows use clearly labeled prototype data.

Supported flows:

- Customer: role selection -> customer shell -> sample scan -> result -> report.
- Officer: role selection -> demo login -> dashboard -> shared scan -> result/evidence/report.

Non-functional requirements: responsive mobile-first UI, English/Hindi/Marathi localization, independent light/dark persistence, accessible controls, no exposed secrets, and no unsupported statutory or real-world claims.
