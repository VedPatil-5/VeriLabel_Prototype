# VeriLabel (Prototype)

> **Notice:** This application is a **prototype** developed for demonstration and concept validation purposes only.

VeriLabel is an AI-assisted packaged commodity inspection prototype designed to verify packaging labels against statutory Legal Metrology (Packaged Commodities) Rules, 2011 (PCR 2011) and FSSAI standards.

---

## Key Features

- **Automated Label Inspection**: Detects mandatory declarations (Net Quantity, MRP, Unit Sale Price, Manufacturing/Expiry Dates, Manufacturer details).
- **Interactive Bounding Boxes**: Visualizes detected optical text regions and flags infractions in real time.
- **Form LM-VI Inspection Dossier**: Generates downloadable, standardized PDF inspection audit reports.
- **Preloaded Test Datasets**: Includes compliant and non-compliant sample packaged commodities to test compliance logic.
